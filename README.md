# Crew of One

A friendslop party game for your browser: 2–8 friends join a room with a
4-letter code and jointly pilot ONE wobbly giant robot through an obstacle
course — one player is the LEGS, one is the ARMS, one is the HEAD/BALANCE.
Falling over is half the fun.

## Play it locally

```
npm install
npm start
```

Then open http://localhost:3000.

See `PROGRESS.md` for build status and the development plan.
