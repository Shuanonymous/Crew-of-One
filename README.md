# CREW of ONE

**V1 (live): https://crew-of-one.onrender.com** · **V2 preview: deploy from
the `claude/v2-visual-mech-rebuild-wu5u5g` branch (see PLAYTEST.md)**

Cinematic co-op mech combat in the browser. 2–8 pilots join with a 4-letter
code and crew **ONE giant war machine** — someone is locomotion, someone
runs each arm, someone is fire control. Before deploying, the whole crew
customizes the shared mech together in a 3D hangar: frame, head, torso,
arms, legs, shoulder ordnance, armour kits, paint, markings and callsign —
with role-owned stations, named proposals, votes, locks and a ready check.
Then you hold the district of Port Meridian against the Abyssals while
storms roll through.

**Modes:** Classic Wave Defence (waves + safe refit) · Endless Escalation
(the threat clock never stops) · Mech Duel (mirror-build crew vs crew) ·
Training (proving ground with live component swapping)

Every field upgrade you buy physically bolts onto the mech — plate,
pods, cannon, thrusters, emitter hardware — visible to the whole crew,
previewable in the shop before you spend.

## Run it

```
npm install
npm start        # open http://localhost:3000
npm test         # server logic + rooms + loadout + full browser E2E gate
npm run visual   # regenerates docs/visual-review/ screenshot evidence
npm run qa       # everything + 5-minute soak/perf bot
```

No accounts, no database, no build step. One Node service serves the files
and the websockets. All assets are generated by code — nothing downloaded
(ATTRIBUTION.md).

## Deploy it (free)

Deploy-ready for Render (`render.yaml`, includes the separate V2 preview
service), Railway, Fly.io, or any container host. Plain-language
instructions: **PLAYTEST.md**.
